Typhoon-Driven Flood Occurrence Prediction in Western Visayas Using Machine Learning

Western Visayas gets hit by typhoons almost every year, and flooding is one of the biggest risks that comes with them. This study looks at whether satellite rainfall and typhoon track data can predict flood occurrence at the province level, and which factors actually drive those predictions.

Data
CHIRPS v2.0 daily rainfall and IBTrACS typhoon tracks, 25 years
Models
Logistic Regression, Random Forest, XGBoost and SVM, explained with SHAP
Published
Zenodo, June 2026, CC BY 4.0

Version 1 defined a flood as rainfall at or above each province's 90th percentile, so the models were partly predicting heavy rain from heavy rain. Version 2 uses observed flood records and terrain features instead.

Preprint (DOI) Code on GitHub
Proposal approvedPaper in progress

Reading the Signs Early: Predicting El Niño-Driven Palay Production Shortfalls in Western Visayas

This project classifies, province by province and quarter by quarter, whether palay production is likely to fall short, using lagged El Niño signals and satellite measures of rainfall and crop health.

Data
PSA palay statistics, NOAA ONI, CHIRPS, NASA POWER, MODIS NDVI
Method
CRISP-DM, province-quarter shortfall classification
Course
Advanced Data Mining, Master of IT, WVSU

Started as a course project in October 2026. I'm now expanding it into a full IEEE-format paper.
